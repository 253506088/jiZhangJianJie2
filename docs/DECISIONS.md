## M03 · 存储与关系

- 统一模型在 TypeScript 校验全部关系，Android 的私有 SQLite 与 Web 的 IndexedDB 通过同一存储接口提交校验过的完整快照。一次导入在一个草稿中建立分类/账户/流水，最终一次验证、一次事务保存。
- 首次初始化不注入演示流水/分类；原型入口完全独立，不使用正式数据库。
- 保存版本单调递增，陈旧写入失败；成功回执发生在底层事务提交之后。校验损坏时保留现有数据并提供显式历史点恢复，不静默回退空账本。
- 历史路径别名只由用户明确改名/合并产生；后续导入可复用这些映射。未确认语义的近义分类不自动合并。
- Excel来源日期可保留原表示，流水支持可选时分秒；编辑不指定时间时不抹掉原时间。

## M04 · Excel确认与重复处理

- 自动表头只是候选，用户可在设备本地选择日期/金额/收支/两级分类/账户/账本等列，缺失或歧义不静默猜测；查看结果后才提交。
- 同文件按SHA-256、目标账本、工作表及原始行号识别来源。保留批次sourceRows，即使用户后来删除某笔，重导也不会把它复活；允许分日期或分工作表补导未导入行。
- 对不同文件内容相同的记录只提示候选，由用户确认范围后保留独立流水；不按金额日期备注的表面一致删除真实记录。
- 错误行默认阻止导入。用户可明确选择仅有效行并保存完整错误报告；草稿最终统一校验和原子保存。
- 用户不希望实验工具占C盘：大型镜像、AVD、运行临时目录和后续项目缓存均放D盘；C盘现有共享SDK/JDK不移动或删除。
