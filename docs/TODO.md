# 简洁记账重制 · 执行清单

目标：独立、离线可用的 Android App；延续旧版 UI/操作习惯；用户手动导入原 App 的 DB/Excel 后，分类可继续使用，新旧流水在同一分类下正确统计，并可按年与原版Excel逐笔对账。每项通过对应检查后勾选，并以同名里程碑单独提交、推送。
