# 年度 Excel 对账

入口是独立的 `ReconciliationPanel`，只接收账本快照和关闭回调；没有持久化或记账命令依赖。读取工作簿和对账各自在可取消的 Worker 中运行，结果对应当时的账本快照，快照变化后需重做。

支持旧版 4.8.8 的支出、收入、转账、借贷四表原始列结构。每张表必须保留第 2 行导出范围和第 3 行表头。全年范围接受本年 1 月 1 日至次年 1 月 1 日，或本年 12 月 31 日；非全年文件会显示可读行的比较结果，但不会宣布年度通过。表顶部的支出、收入合计也须与可读行相符。

比较限定一个账本和一个日历年。配对键由收支类型、日期/分钟、完整分类身份、账户/转入账户、成员/借贷人、借贷子类型、转账标签、原样备注组成。分类和成员的明确改名或合并别名用于找到当前身份；不按同名二级分类汇总。原版 Excel 时间只有分钟，数据库保存的秒仅按分钟比较；Excel 没有流水稳定 ID，不能证明两个完全相同记录的先后身份。

同配对键下按金额多重集比较，保留重复笔数。先消耗两侧相同金额的同等数量：剩下唯一一对为金额不同，仅一侧有记录为缺少/多出，两侧多个候选为对应不唯一。不会通过排序强行把歧义变为逐笔金额差额。元数据改动可能显示为一笔缺少和一笔多出，需要用户查看明细确认。

只有全年覆盖、所有行可解析、所有必要字段明确、顶部合计一致、逐笔完全匹配时才通过。表头固定为已核实的第 3 行；数据区的非空合计行或重复表头不能沿用通用导入的跳过策略，均以来源行号报告并阻止通过。真正空白行可忽略。

对账另外核查原始账户、支出两级分类、收入类别、成员、借贷人/类型、转入账户及分钟时刻，不能把缺失值与新版默认值相同视为验证成功。备注和旧版实际为空的普通转账类型仍可留空；收入的固定父类“收入”由已核实的单层格式决定。跨年源行、错误行、时刻缺失和默认补齐字段都阻止通过。这些限制只属于对账，不修改可由用户确认的通用 Excel 导入策略。此功能校验明细，不验证预算、模板或账户期初余额。

默认导出 JSON 只含年份、类型笔数、结果、来源表行号和本次比较位置，不含金额、具体日期、名称、备注、ID 或文件名。用户勾选“显示并导出金额、日期、账户、备注等明细”后才能显示、导出完整差异。报告始终留在用户选择的本地文件路径。

模块测试使用提交的原包虚构 XLS，年度元信息变体在内存中生成，不改动原文件。浏览器测试同样只读取该虚构夹具，覆盖年度通过、单笔错 1 分、脱敏导出、月度文件阻止通过及重启不改账本。
