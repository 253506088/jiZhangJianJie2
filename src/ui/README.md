# 正式界面与原版行为对齐

此目录只负责界面和交互，所有写入通过外部 `mutate`，持久化成功后才显示成功。数据模型、Excel 导入、备份和原生文件操作分别在其他模块。

## 接口

`ProductionApp` 接受状态、忙碌状态、异步 mutate，以及导入/导出/恢复/保存点回调；`ProductionAppHandle.back()` 供 Android 返回键使用，`showTransactions()` 供导入完成后切到对应账本和月份。

## 已落地的原版结构

- 支出/收入/转账/借贷四页签。支出左一级右二级，收入单层可见类别；数据层隐藏父类和迁移遗留的不同父级不会被擅自合并。
- 普通记录有成员，默认通过 self 角色选择“自己”，不依赖名字或写死 ID。借贷单独选择借贷人。
- 借入、借出、还款、收款分别调整账户进出，不计入普通收入/支出。账户合计与借贷净额分开展示，避免把借款伪装为收入或重复扣减账户余额。
- 借贷明细显示当前筛选范围的资金流入、流出与借贷净额，避免用普通收支的零值替代借贷情况；它不冒称包含未导入的历史。
- 新安装默认概况首页/蓝色，保留经典首页和珊瑚配色；既有 v1 数据由模型迁移保留经典样式。提供 9 种配色、明暗模式和跟随系统。
- 概况采用原版的预算区、日/周/月收支卡片、左菜单/中央记账/账户/报表/更多底部结构；本轮增加本年概况和全年明细跳转。默认插画是项目自己的账簿 SVG。
- 成员、借贷人可新增、改名、排序和归档；归档只隐藏新记录选择，历史编辑保持原关联。

## 保存与返回

- 金额键盘进入时展开，点击金额可再次展开，填写备注/日期等可收起，避免与系统输入法堆叠。
- Android 返回在数字键盘展开时先收起，再次返回才触发未保存保护；可见返回按钮直接执行页面离开保护。
- 支出“再记一笔”保留当前分类；金额/备注清空、日期和时分更新、数字键盘重开。
- 原包已确认的收入和转账“再记一笔”回到支出，保留原账户/成员。转账保留的是原账户，不是目标账户。界面显示明确提示，避免误把下一笔当作收入或转账。
- 保存错误在原生 dialog 内可见，所有忙碌表单禁用；非交互提示不拦截底部按钮。外部已更改/删除的记录不能被旧编辑表单覆盖。

## 预算与连续录入

日、周、月预算独立设置；支持按期重复或仅指定周期，分类预算只扣覆盖范围内的支出。总体额度优先，否则按不重叠的父子分类范围汇总。本周从周一开始。概况结余率为普通收支结余除以收入，整数截断；没有收入时明确显示破折号。普通收支卡片使用全部收支，不受预算覆盖范围限制。

借贷“再记一笔”回支出时恢复此前普通账户与成员，借贷账户和联系人独立保留。手动选择历史日期后再记会恢复今天。以上行为有原包控制实验依据。新开编辑页沿用最近有效普通账户/成员是连续录入的设计选择；没有历史时回到现金/自己，不把旧数据缺失成员伪装成已知身份。

测试见 `tests/e2e/`：既有经典交互、概况/四类型/成员，以及未修改原 APK 实际导出的虚构 `.xls` 已分别覆盖。Web 通过不能代替 Android IME、返回键和本机 SQLite 的验收。

## 第二轮界面优化

- 四种记账类型紧凑排列，与跨一级分类关键词搜索共用一行。结果展示完整父子路径，点击后使用原有稳定分类身份；不混入其他账本或收支类型。
- 五列四行金额键盘支持加减乘除。先乘除后加减，金额模块用精确有理数计算并在最终结果舍入到分；计算错误不能保存。
- 首页背景支持本机 JPG/PNG/GIF/WebP，预览后应用，保留原始动画字节；显示方式和图片随完整备份保存。可随时恢复默认插画，两种首页均支持。
- 年度 Excel 对账使用独立只读面板，逐笔核对数量和金额；默认差异报告只给类型、数量及来源位置，用户可显式展开明细。非完整年度或不可确定的记录不能报告通过。
