# 简洁记账 · 新

独立重制的离线记账 App，延续简洁记账4.8.8的主要布局和操作习惯。使用 React、TypeScript、Vite 和 Capacitor；Android 私有 SQLite 保存账本。原版业务源码未恢复，本项目依据未修改 APK 的实际运行、资源和虚构导出样本重新实现。

开发根目录是 `D:\code\my\2\记账`。正式入口位于src/和android/；旧界面预览保留在prototypes/ui-v1，使用独立入口和演示状态。

## 构建与安装

**双击根目录 `build-apk.bat`**，生成 `artifacts/jizhang-jianjie2-release.apk`。窗口显示结果，APK经过签名和对齐校验。首次需下载依赖，之后使用D盘缓存。

将APK传到手机，使用系统安装器安装。包名 `dev.keepaccounts.jianjie2`，与原版可同时保留。支持Android7.0及以上，需Android System WebView111或更新版本；旧组件会显示更新提示。

详见 [构建和签名说明](docs/BUILD.md)。**请安全备份 `.local/signing`；以后覆盖更新必须保留同一私钥。** 签名密码和私钥不进入Git。

## 第一次使用

1. 新安装是空账本，没有演示流水。打开“更多 → 从旧版 Excel 导入”，在手机上手动选择原版导出的.xls或.xlsx。
2. 核对识别的工作表、列映射和收支类型，再看笔数、日期范围、金额及分类预览；错误行默认阻止导入，只有明确确认后才允许仅导入有效行。
3. 确认导入后，父子分类、账户、成员和借贷人会一并建立。记账时直接选已有一级/二级分类，新旧流水使用同一分类身份统计。
4. 在报表切换“全部月份”可核对跨年的历史数据。分类改名保留历史关联；要整理已有重复分类，请使用分类管理里的合并预览。
5. 原版Excel没有期初余额、预算、模板或完整账本身份。请自行核对账户余额并设置期初值；日周月预算需要单独配置。
6. 定期通过“导出完整备份”保存.jzbackup，可选密码加密。换手机使用“从完整备份恢复”，先核对再确认替换全部账本。

助手开发和测试只使用虚构数据。真实文件由用户自己在App内选择和核对，不需要交给开发助手。

## 已实现

- 概况/经典首页、9种配色、暖白/夜间/跟随系统。
- 支出两级分类、收入单层类别、转账及借入/借出/还款/收款；金额使用整数分。
- 数字加减键盘、保存/再记一笔、日期时间与备注、成员与借贷人、常用模板。
- 明细搜索/筛选/编辑/删除、分类排序/改名/归档/合并、多个账本和账户、期初余额。
- 分类报表与钻取，日周月独立预算，预算范围不改变普通收支统计。
- 原版四表Excel导入/导出、导入批次记录、重复文件识别、完整明文/加密备份与历史保存点恢复。
- 原子提交、摘要校验、大账本流式读取、保存完成后再反馈成功、系统返回和未保存内容保护。

类别身份由账本、收支方向和完整父子路径确定。“餐饮/其他”和“交通/其他”保持不同；同一分类的新旧记录合并统计。不会只凭同名子分类或相同日期金额删除/合并流水。

## 离线与迁移边界

Android正式包没有网络权限、账号系统、广告或分析SDK。文件由用户通过系统选择器选取和保存；若主动选择系统中的云文件提供器，其同步由对应服务处理。Web开发预览有独立IndexedDB，不与手机SQLite自动同步。

Excel用于交换明细；**完整备份用于完整迁移**，保留分类ID、路径别名、预算、模板和导入来源。不要把Excel导出当完整备份，也不要先卸载旧App再核对迁移。

导入文件上限32MB、候选记录20万，XLSX解压上限128MB；实际能力受设备内存影响。导出XLS每表最多65,533笔，超限明确拒绝，可选XLSX或缩小日期范围。完整备份文件上限96MiB、状态正文64MiB；已用10,000笔虚构账本验证Android升级和约4.8MB备份无损。

主要兼容依据是原版4.8.8实测格式；其他版本可以手动映射字段，仍应自行核对。未知负数不自动改成正数，缺失或异常字段会提示。未实现原版云同步、第三方支付自动采集、iOS发行工程；未宣称所有厂商手机均已验证。

## 开发维护

```powershell
npm ci
npm run dev
npm test
npm run test:e2e
npm run build
npm run format:check
```

开发预览为 http://127.0.0.1:5173/ 。`npm run dev:prototype` 在5174打开冻结的演示版。Node.js只用于开发构建，手机不运行Node服务。本机原有24.13.0即可，本项目不依赖REA专用24.22.2。

| --- | --- |
| src/core | 金额、分类身份、账本规则、统计、预算和数据版本迁移 |
| src/storage | Web IndexedDB / Android SQLite、原子写入与保存点 |
| src/imports、src/exports | Excel工作器、映射校验、导入计划和四表导出 |

| src/ui、src/App.tsx | 界面与交互、工作流接入；保存交给数据层 |
| android、scripts | 原生插件、签名构建和隔离设备验收脚本 |
| tests/fixtures、tests/e2e | 已核对来源的虚构样本、浏览器端到端测试 |
